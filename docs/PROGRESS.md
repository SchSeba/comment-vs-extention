# Local Review development status

The current scope uses the built-in Source Control diff, pending comments and one summary per addressed comment. Git history remains in Source Control, and Codex keeps its own chat history. The extension stores the live review records outside the worktree and allows the user to dismiss them. Both Codex clients use the same local MCP server.

- Built the VSIX and installed it in a Task Tracker-derived image on rootless Podman. The test IDE is available on localhost port 18765 with web password disabled and named volumes for Codex, VS Code settings and worktrees.
- Tested a disposable cloned worktree in Chrome. Opened its changed file from Source Control, created comments on two different lines, and verified the follow-up clipboard action. The MCP server returned both IDs, line numbers and original excerpts. The harness edited the fixture, supplied a different summary for each ID and reopened the worktree in a fresh browser session. Both summaries appeared on the corresponding native comments.
- `npm test` passed the stdio MCP checks for worktree separation, concurrent replies, idempotency and dismissal. `npm audit` found no known vulnerabilities in the locked dependencies.
- Passed signed-in tests in the integrated terminal and official Codex sidebar using separate disposable clones. Each Codex conversation made the initial edit, read two native review comments, applied both requested fixes, and wrote two distinct replies and two short final summaries. The dev image pins official Codex extension 26.908.40401 after the auto-updated release timed out in the browser. Automatic submission to a selected IDE chat remains blocked on an official interface. - Rebuilt and redeployed the pinned image on port 18765 with the original volumes. Confirmed ChatGPT login persisted and repeated the signed-in sidebar test on that deployment. Reopened both completed test worktrees in fresh browser sessions and saw each agent reply on its corresponding comment.
